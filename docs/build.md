# Сборка проекта

## Настройки сборки и доступные платформы

Доступна платформа Windows. 
В список сцен для сборки добавлена сцена PlatformerDemo с индексом 0.

## Установленные пакеты

Основные пакеты проекта: 2D Animation, 2D Aseprite, 2D PSD Importer, 2D Sprite, 2D SpriteShape, 2D Tilemap, 2D Tilemap Extras, Input System, Universal Render Pipeline, Timeline, UGUI, Visual Scripting, Test Framework, Assistant.

В проект также импортированы ассеты из Asset Store-пакета Simple 2D Template
